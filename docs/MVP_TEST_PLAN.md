# План проверки MVP (Windows 11)

Никакая функция ниже не считается проверенной на реальном рабочем столе без соответствующих данных. Собранный exe и автоматические unit-тесты — не эквивалент ручного smoke test.

## Предусловия

- Не отключать Explorer, не запускать панель с повышенными правами.
- Зафиксировать Windows build, процессор, GPU, DPI, количество мониторов, частоту экрана.
- Проверить наличие штатной панели задач и возможность закрыть нашу панель кнопкой Exit.
- Команды: \`cargo fmt --all -- --check\`, \`cargo test --all-targets\`, \`cargo clippy --all-targets -- -D warnings\`, \`cargo build --release\`.

## Приёмочные сценарии

1. Стартует на Windows 11 и появляется чуть выше штатной панели, без изменений Windows Explorer и трея.
2. Если открыть/закрыть Notepad, Edge и другое desktop-приложение, список окон обновляется.
3. Нажатие названия окна активирует приложение; повторное нажатие активного — сворачивает его.
4. Кнопка Start открывает штатный «Пуск», Search — поиск, +N — Task View.
5. Часы меняются на следующей минуте и после ручной смены времени в Windows.
6. При 10+ окнах на узком экране появляется +N без выхода кнопок за край.
7. После Exit штатная панель Windows остаётся в нормальном состоянии.
8. Проверить 100/125/150/200% DPI, смену разрешения и полноэкранную игру; записать дефекты.
9. Проверить стандартную и повышенную привилегии приложений (UIPI может ограничивать активацию).
10. Проверить ложные/пропущенные окна, UWP/WinUI, переход между виртуальными рабочими столами.

## Метрики

- В простое 5 минут: CPU (% одного логического процессора), private working set и GPU usage.
- Частота repaint в простое и при 10 действиях/сек; количество WM_PAINT и время paint (ETW/профайлер).
- Реальные frame-time/180 Гц сейчас **не тестируются**: GDI-прототип не имеет compositor animations.
- Для M2 понадобится DirectComposition/Windows Composition и PresentMon/ETW.

## Известное поведение

- Если Shell Hook не регистрируется, включается fallback-сканирование окон раз в 5 секунд.
- Приложение не получает содержимое системного трея (для этого нет универсального задокументированного публичного API).
- Нет системного автозапуска и инсталлятора. Это намеренное ограничение.

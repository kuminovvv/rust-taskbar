# Функциональная матрица Windows 11 Taskbar

Срез требований: 2026-11-18. Зависит от сборки Windows и канала обновлений. Это каталог пользовательских сценариев, а не гарантия доступности API для сторонней панели.

Приоритеты: **P0** — минимально полезная панель, **P1** — ежедневная замена стандартной, **P2** — расширение. Статусы реализации отсутствуют: код ещё не написан.

## Не входит в первую версию

- Замена `explorer.exe`, `Shell_TrayWnd`, вмешательство в системные процессы.
- Реализация собственного Start, Search, Notification Center и Widgets.
- Неподдерживаемые private Windows Shell API без отдельного решения и предупреждений.
- Гарантия полной совместимости со всеми приложениями без испытаний.

## Контрольные сценарии для P0

1. Запуск, переключение, минимизация и закрытие 10+ окон разных приложений.
2. Переход между окнами в пределах одного приложения.
3. Корректная смена активного приложения, закрепление и сохранение порядка.
4. Меню «Пуск» и поиск Windows доступны с клавиатуры и мыши.
5. Корректно работает на 100%, 125%, 150% DPI; полноэкранная игра не перекрывается.
6. Выход из нашей панели не оставляет повреждённой/неработающей оболочки Windows.

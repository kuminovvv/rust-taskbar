# Правила разработки Rust Taskbar

1. Язык: Rust. Платформа: Windows 11. Никаких Electron/Tauri/WebView2 без принятого ADR; по умолчанию нативный Win32 + GPU composition.
2. До завершения M0 не начинать глобальную замену shell и интеграцию с реальным системным треем через неофициальные хаки.
3. Не останавливать `explorer.exe`, не выключать службы Windows, не менять системные файлы, реестр shell или пользовательский автозапуск в тестах.
4. Изменения системных настроек, установка, автозапуск — только с разрешения и с работающим откатом.
5. Отрисовка по событию, без 180-FPS busy loop в простое. Нужны метрики, profiling и тесты на падения.
6. Каждый новый функциональный блок: тесты + документирование совместимости и деградации при ошибке Windows API.
7. Функции, не проверенные на реальных сборках Windows, маркировать «гипотеза/PoC», а не «работает».
8. Публикация релизов, деплой, push и установка на основной ПК — по отдельному согласованию.

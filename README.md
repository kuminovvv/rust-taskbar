# Rust Taskbar (working title)

Лёгкая, нативная панель задач для Windows 11 на Rust. Статус: **discovery / specification**. Реализация ещё не начата.

## Цель

Сделать отзывчивую панель задач, которая сохраняет необходимые сценарии штатной Windows 11, не требует Electron/WebView2 и практически не потребляет ресурсы в простое. Цель анимаций — синхронизация с дисплеями до **180 Гц** (при поддержке монитором и ОС). Это **целевой показатель**, а не подтверждённый результат.

## Принципы

- Rust + Win32 API (`windows-rs`); исследовать DirectComposition/Windows Composition для анимаций с GPU-композицией.
- Event-driven state updates: никаких периодических полных опросов списка окон и непрерывного render-loop в простое.
- Сначала работает **рядом с Explorer**, без замены Windows Shell, отключения служб и модификации системных файлов.
- Не пытаться в MVP подменить/перехватить системный трей: сначала прототип и проверка совместимости.
- Автозапуск, замена штатной панели и изменение пользовательских настроек — исключительно по явному выбору пользователя.

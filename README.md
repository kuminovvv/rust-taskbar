# Rust Taskbar

Экспериментальная панель задач Windows 11 на **Rust + Win32**, без Electron, WebView2 и фонового 180-FPS render loop.

> **Статус: MVP / прототип.** Приложение сейчас работает как **плавающий Dock поверх штатного Explorer**. Оно **не заменяет системный трей, меню «Пуск» или саму оболочку Windows**. Полная замена панели и GPU-анимации ещё не реализованы.

## Что реализовано

- Нативное безрамочное окно Win32, расположенное над стандартной панелью в рабочей области основного монитора.
- Список видимых top-level окон, получаемый через `EnumWindows`; фильтрация технических и cloaked-окон.
- Shell Hook уведомления для событий открытия/закрытия/активации; резервный опрос раз в 5 с, **только если** Shell Hook недоступен.
- Переключение на окно, восстановление свёрнутого окна, сворачивание активного.
- Кнопки **Start**, **Search**, **+N** (Task View), **Exit**.
- Часы по локальному времени с таймером, синхронизированным на смену минуты.
- Простая двойная буферизация GDI; отрисовка по WM_PAINT, без постоянного render-loop.
- Учёт DPI основного монитора, клавиша Esc для выхода, автоматических системных изменений нет.
- Unit-тесты геометрии кнопок и проверка сборки через GitHub Actions (Windows).

## Запуск

Требования: Windows 11 x64, актуальный stable Rust (MSVC toolchain).

```powershell
git clone https://github.com/kuminovvv/rust-taskbar.git
cd rust-taskbar
cargo run --release
```

Панель появится **над** штатной панелью Windows. Нажмите `Exit` для выхода. Программа **не** отключает Explorer, не устанавливается в автозагрузку, не меняет системные настройки и не требует администратора.

Для готового exe после успешной CI-сборки: GitHub → Actions → `Rust Windows CI` → артефакт `rust-taskbar-win64-unsigned`. Поскольку exe не подписан, Windows может вывести предупреждение SmartScreen.

## Известные ограничения

- **Нет** закрепления приложений, трея, иконок процессов, превью окон, группировки, кастомизации, мультимониторного размещения.
- GDI — временный event-driven рендерер, **180 FPS / GPU-анимации пока не реализованы**. Частота обновления монитора сама по себе не означает аналогичный FPS приложения.
- На некоторых приложениях Win32 может возвращать пустой заголовок/не позволять активировать окно.
- Кнопки Start/Search используют `SendInput`; ограничены защитой Windows, активными модификаторами и контекстом удалённого доступа.
- Это prototype UX: недоступны screen-reader UIA и keyboard focus navigation; до полноценного релиза их нужно реализовать.
- Возможные проблемы при fullscreen, DPI и некоторых расположениях Explorer — требуется тестирование на целевой Windows 11. При закрытии штатная панель остаётся доступна.
